# Catálogo de macros de restaurantes

Fuente: *Macros restaurantes vol. 3* (Mariale Coaching). El código es dueño de
las kcal (`4P + 4C + 9G`); aquí solo van proteína, carbo y grasa por porción.

Un `id` de plato no se reutiliza dentro del mismo restaurante. El Sombrero
vueltiao y otros repetidos del PDF quedan en una sola fila.
